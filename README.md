# 🏡 Orouba Square – Premium Real Estate Landing Page

A modern, responsive, and high-performance real estate landing page built using **Vanilla HTML, CSS, and JavaScript**. The project showcases luxury residential communities with an elegant UI, smooth animations, and a premium user experience.

## 🌐 Live Demo

**Website:** https://orouba-square.vercel.app/

---

# ✨ Overview

Orouba Square is a premium real estate website designed to present residential and commercial projects in a modern and engaging way.

The website focuses on:

* Luxury visual experience
* Fast loading performance
* Responsive design
* SEO optimization
* Interactive user interface
* Elegant animations
* Mobile-first experience
